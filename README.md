# Kannada-OCR
Conversion of Hand written Kannada  Characters From Images Into Editable From Using Image Processing Techniques As English has the set of vowels and consonants, Kannada also have hybrid characters like ottaksharas, kaagunithas etc, hence recognising of those characters is the complex knot. Optical Character Recognition (OCR) is the technique used to extract data from 
handwritten text or printed text in to machine-encoded form. Further steps can be followed data processing like searching. Work has been done using SVM (Supprot Vector Machine, database approach in order to recognise the handwritten Kannada characters. As this project concentrating mainly on grocery shop bills, the handwritten characters in Kannada as well as English is extracted. The numbers which is mention as cost of the each item is also recognised. This project aims to findthe total cost that customer has to give. In existing system work has been already done regarding scripts, letters and extracting handwritten characters from it. High tech malls have specific device such as QR code scanning for each items. But in grocery shops still they are using handwritten bill. In order to avoid mistakes and to save time, by using Image processing and Deep Convolutional Neural Networksthis project aims to provide the bill in editable as well as printable format so that every customer can get the printable bill from small grocery shops which ensures digitalisation.
